# System Map

```text
User-approved Parent Goal
  -> Control Plane: task graph / state / Human Gate / completion contract
     -> Policy Engine decision (external; has priority)
        -> lead selection: Manual -> Deterministic -> Capability
           -> Codex or Antigravity adapter
              -> normalized Result Packet
                 -> integrate unresolved work / new work / recommendation
                    -> next ready task or terminal validation

GitHub private inbox -> Actions template -> labeled self-hosted runner -> local handoff receiver
Drive -> human-readable index, archive, and handoff material only
```

The local bridge remains historical evidence of a macOS-focused mailbox design. It is not used as the control plane and has not been promoted as current live interoperability evidence.
