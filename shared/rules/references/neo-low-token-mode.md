# Neo Low-Token Mode（跨平台瀏覽器低用量預設原則）

適用於所有本地專案及一般網頁任務。涉及瀏覽器／網頁操作時，優先使用 `browseros-neo` MCP（各平台禁用／降順位之備援工具名稱由各 Runtime Adapter 指定），並預設啟用低用量模式：

## DEFAULT（預設低用量原則）

1. **排除非必要媒體**：不主動讀取、分析、下載或播放與任務無關的廣告、圖片、影片、音訊。
2. **文字與結構化優先**：優先取得純文字、DOM/AX 結構化資料或本地檔案輸出。
3. **精準局部擷取**：優先使用 `run`（搭配 `maxChars`）、`grep`、`read`（`format: "text"|"markdown"`、`selector`、`viewportOnly: true`、`includeImages: false`）與 `snapshot(mode="interactive", depth=...)`；避免非必要完整頁面 `snapshot(mode="full")`；`act` 優先傳入 `diff: "summary"` 或 `"none"`。
4. **禁用非必要截圖與視覺**：除非任務明確需要視覺辨識或文字方案無法完成，否則不使用 `screenshot`、影像輸入或影音分析。
5. **批次與重用**：大量重複網頁操作優先批次執行（單次 `run` 腳本），重用既有 HTTP、Playwright、Neo `run`、saved helpers 或 `run_skill` 等已驗證能力。
6. **大結果落地本機**：大型擷取結果優先保存於本地結構化檔案（或沿用 Neo 回傳的檔案路徑），模型僅接收必要欄位、摘要、待補證項目與例外資訊。
7. **不重複讀取**：避免重複讀取相同頁面與已取得資料，優先重用仍有效的既有證據。
8. **不犧牲正確性**：不得因節省 Token 而犧牲必要資料、分頁完整性、正確性或正式驗收。

## EXCEPTION（最小範圍、最短期間）

僅於下列情況暫時放行必要資源，任務完成後立即恢復預設低用量模式（且不得作為繞過網站安全限制的理由）：

- 使用者明確要求圖片或影音任務。
- 網頁操作必須依賴視覺資訊（如版面異常或驗證需求）。
- 必要圖片包含任務所需資訊。
- 資源封鎖造成網站功能或資料缺漏。
- 其他無法以文字或結構化資料完成的任務。
