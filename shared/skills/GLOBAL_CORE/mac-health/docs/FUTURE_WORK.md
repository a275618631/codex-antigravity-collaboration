# mac-health 未來發展規劃 (Future Work)

本文件記錄後續延伸規劃。

---

## 1. Mole 實體安裝與執行授權

- 當前環境尚未安裝 Mole 工具，本機已具備完整的 `MoleAdapter` 唯讀與 Dry-run 模擬介面。
- 未來若使用者安裝 Mole，可直接啟用實體 Dry-run 與安全審查清理流程。

---

## 2. 長期歷史趨勢與多點採樣

- 目前 `iostat` 與 CPU 取樣為 1 秒快照，後續可支援可選的短時間滑動平均（例如 5 秒多點採樣）。

---

## 3. 架構紀律守則

- **拒絕不必要的常駐架構**：目前維持 100% 無 daemon、無 DB、無背景 watcher、無 MCP 侵入之極簡架構。
