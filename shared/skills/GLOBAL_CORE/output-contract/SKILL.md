# 交付契約

收尾時用最少必要資訊讓使用者知道成果是否完成、改了什麼、如何驗證，以及還有哪些限制。

## 必要欄位

```text
完成狀態
- ...

修改清單
- ...（無修改則寫「無」）

驗證
- 指令／方式：結果

待確認事項
- ...（無則寫「無」）
```

- 未執行、失敗、跳過或需人工判斷的項目要明確標示，不把建議寫成已完成。
- 不貼大量檔案內容；列出實際路徑與必要連結即可。

## 高風險附加欄位

涉及設定、同步、刪除、遠端、憑證或資料搬移時，加上：

```text
風險與保護
- ...
```

若完成同步、commit 或 push，只回報實際成功的動作；不得暗示未執行的外部變更。
