# Claude-inspired 視覺與 Artifact 參考

只有使用者要求 Artifact、文件、簡報、UI 或其他視覺產出時才載入本參考；一般文字回覆不需要。

## 視覺原則

- 內容先於裝飾：先讓讀者看懂主訊息、依據、限制與下一步，再處理美化。
- 以克制、溫暖、清楚、理性、有編輯感與適合長時間閱讀為目標；避免高飽和科技色、螢光、厚重陰影、發光、無意義動畫與裝飾性插圖。
- 建立清楚階層：標題、摘要、章節、證據／細節、限制／風險、建議／結尾。優先使用可讀行長、留白、對齊與穩定間距，並驗證基本對比度與鍵盤 focus。
- 字體只使用已存在、已授權或安全 fallback；token 依品牌、對比度與媒介調整，不把示例色值當成硬性規範。

## Artifact 結構

- 將內容模型與呈現層分開；可重用欄位包括 `title`、`summary`、`sections`、`evidence`、`limitations`、`recommendations`、`sources`。
- 元件只抽象清楚且可泛化的責任，例如 `DocumentHeader`、`Section`、`EvidenceBlock`、`DataTable`、`ChartFigure`、`LimitationNote`。
- 依媒介選少量可組合範本，不用單一版型強制所有內容，也不為單一畫面建立不可重用架構。

## 視覺驗收

依任務需要檢查響應式版面、列印／匯出、文字截斷、留白、圖表解讀、重要資訊位置、鍵盤操作、focus 狀態與色彩對比；只執行與專案相稱的檢查。
