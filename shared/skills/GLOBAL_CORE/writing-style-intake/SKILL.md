# 文字風格確認

先判斷風格資訊是否真的會改變成品，再決定詢問或直接寫作。此 Skill 負責風格邊界與自然度，不取代 DOCX、簡報、PDF 或試算表等專用技能。

## 決策邊界

1. 檢查使用者是否已提供語氣、正式程度、讀者、目的、格式或參考範例。
2. 若資訊足以執行，簡短重述採用風格後直接開始。
3. 使用者說「你決定」、「照原文」或要求延續既有風格時，對缺漏採用保守合理預設，不追問。
4. 校正錯字、短句翻譯、單句改寫或固定格式填入，不額外詢問。
5. 只有缺少的讀者、目的、格式或語氣會明顯改變成品時，才問一個關鍵問題並提供精簡選項；不要進行第二輪盤問。

## 寫作規則

- 使用台灣繁體中文、台灣常用詞與全形中文標點；專有名詞依慣例保留原文。
- 優先使用清楚主詞、動詞與具體資訊，刪除不影響意思的開場、收尾、空泛拔高與同義反覆。
- 保留原始事實、數字、專有名詞、引文與使用者立場，不自行補造資料。
- 交付前檢查目的、讀者、篇幅、事實、結構與自然度；只交付修訂後版本，不展示內部檢查過程。

需要任務別選項或提問範例時，讀取 [style-options.md](references/style-options.md)。
