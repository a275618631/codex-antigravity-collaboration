# 文字風格選項參考

只有使用者缺少會明顯影響成品的風格資訊時才載入；不把完整選項表固定塞進每次對話。

## 通用選項

- 自然口語：親切、不做作。
- 專業俐落：重點清楚、句子精簡。
- 沉穩正式：適合主管、客戶或正式場合。
- 說服導向：強調價值、證據與行動。
- 敘事有溫度：有人味、畫面感與情緒層次。
- 自訂：依指定作者、品牌或既有文件調整。

## 任務別優先選項

- 文章：自然口語、知性平實、觀點鮮明、敘事有溫度。
- 履歷／求職：專業俐落、成果導向、穩健正式、個人故事。
- 報告／企劃：高階摘要、分析客觀、決策導向、提案說服。
- 簡報／講稿：高階摘要、教學易懂、提案說服、故事敘事。
- 商務訊息／郵件：簡潔直接、禮貌專業、溫和協調、明確催辦。
- 行銷／社群：品牌專業、自然親切、活潑有梗、轉換導向。

## 精簡提問模板

> 開始前請選文字風格（可回覆代號或直接描述）：A 自然口語、B 專業俐落、C 沉穩正式、D 說服導向、E 敘事有溫度、F 自訂。另請告訴我讀者、用途與篇幅；若沒有偏好，回覆「你決定」即可。

只列與當前任務有關的選項，不把無關選項硬塞給使用者。
