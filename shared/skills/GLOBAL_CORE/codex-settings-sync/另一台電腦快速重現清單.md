# 另一台電腦快速重現清單_20260611

## 目標

在另一台 Windows 或 macOS 電腦登入 Codex 後，手動選擇要套用的 Codex 規則、設定、skills、workflows、execution profiles 與同步工具。

```text
https://github.com/a275618631/codex-settings-sync.git
```

repo visibility：private

## 20260611 更新與封存紀錄

- <span style="color:red">修正：舊版「每日自動 pull」不再使用；拉取遠端設定必須手動選擇來源電腦與分類。</span>
- <span style="color:red">修正：舊版「整包複製 `要同步的Codex設定/`」已改成 `backups/<電腦名稱>/<分類>/` 分類備份。</span>
- 舊流程對比：~~設定每日自動 pull~~ -> 手動執行 `手動拉取分類設定.ps1` 或 `.sh`。

## 遠端備份結構

```text
backups/
  <電腦名稱>/
    agents-root/AGENTS.md
    agents-codex/AGENTS.md
    config/config.toml
    execution-profiles/
      sol-auto.config.toml
      luna-manual.config.toml
    skills/
    workflows/
    sync-tools-and-docs/
    metadata/export-info.txt
```

## 可手動拉取的分類

- `agents-root`：`AGENTS.md`
- `agents-codex`：`.codex/AGENTS.md`
- `config`：非機密 `config.toml`
- `execution-profiles`：`sol-auto.config.toml` 與 `luna-manual.config.toml`
- `skills`：自訂 skills，排除 `.system`
- `workflows`：工作流與可重複 SOP
- `sync-tools-and-docs`：同步腳本與說明文件

## Windows 重現步驟

1. 安裝並登入 GitHub CLI。

```powershell
gh auth login
```

2. Clone 設定 repo。

```powershell
$SyncRepo = Join-Path $env:USERPROFILE "Documents\Codex設定同步"
git clone https://github.com/a275618631/codex-settings-sync.git $SyncRepo
Set-Location $SyncRepo
```

3. 查看可用來源電腦。

```powershell
.\同步工具\手動拉取分類設定.ps1 -Pull -ListSources
```

4. 依需要手動拉取分類。

```powershell
# 只拉 AGENTS.md
.\同步工具\手動拉取分類設定.ps1 -SourceComputer <電腦名稱> -Category agents-root

# 拉 skills 並取聯集
.\同步工具\手動拉取分類設定.ps1 -SourceComputer <電腦名稱> -Category skills -Union

# 拉 workflows 並取聯集
.\同步工具\手動拉取分類設定.ps1 -SourceComputer <電腦名稱> -Category workflows -Union

# 套用 Sol Auto／Luna execution profiles
.\同步工具\手動拉取分類設定.ps1 -SourceComputer <電腦名稱> -Category execution-profiles

# 拉全部分類並取聯集
.\同步工具\手動拉取分類設定.ps1 -SourceComputer <電腦名稱> -Category all -Union
```

## macOS 重現步驟

1. 安裝並登入 GitHub CLI。

```bash
brew install gh
gh auth login
```

2. Clone 設定 repo。

```bash
SYNC_REPO="$HOME/Documents/Codex設定同步"
git clone https://github.com/a275618631/codex-settings-sync.git "$SYNC_REPO"
cd "$SYNC_REPO"
```

3. 查看可用來源電腦。

```bash
./同步工具/手動拉取分類設定.sh --pull --list-sources
```

4. 依需要手動拉取分類。

```bash
# 只拉 AGENTS.md
./同步工具/手動拉取分類設定.sh --source <電腦名稱> --category agents-root

# 拉 skills 並取聯集
./同步工具/手動拉取分類設定.sh --source <電腦名稱> --category skills --union

# 拉 workflows 並取聯集
./同步工具/手動拉取分類設定.sh --source <電腦名稱> --category workflows --union

# 套用 Sol Auto／Luna execution profiles
./同步工具/手動拉取分類設定.sh --source <電腦名稱> --category execution-profiles

# 拉全部分類並取聯集
./同步工具/手動拉取分類設定.sh --source <電腦名稱> --category all --union
```

## 修改後匯出與按需上傳

在任何一台電腦修改 Codex 設定後先執行本機匯出：

```powershell
.\同步工具\自動備份並推送.ps1
```

macOS：

```bash
./同步工具/自動備份並推送.sh
```

以上預設不 Commit／Push。只有使用者主動要求上傳時，由 Luna 使用非受保護功能分支並明確加上 `-ConfirmPush`（Windows）或 `--confirm-push`（macOS）；不得 Merge。

## 聯集規則

- 目錄聯集：skills、workflows 會合併不同檔案與不同資料夾。
- 內容聯集：同名文字檔保留本機內容，並把遠端缺少於本機的文字行附加到檔尾。
- 非文字檔衝突：保留遠端副本為 conflict 檔，不直接覆蓋。

## 不同步清單

- `.env`
- OAuth / Notion / Google / GitHub 登入狀態
- tokens、credentials、auth.json
- 本機 plugin cache 狀態
- OS 工作排程器 / macOS launchd
- 本機路徑、沙盒權限、信任專案狀態
- session DB、暫存、cache
- Codex 內建 `.system` skills
- 外掛 cache 或 marketplace cache
- 影片
- 專案產出程式碼
- 任務輸出資料
