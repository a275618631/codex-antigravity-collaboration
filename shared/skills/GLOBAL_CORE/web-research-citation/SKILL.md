# 網路研究與引用

## 流程

1. 先判斷資訊是否可能過期；若可能，必須查證。
2. 優先官方來源、原始文件、研究論文、法規原文；技術問題優先官方 docs。
3. 比對發布日期與事件日期。
4. 區分事實、來源主張與自己的推論。
5. 回覆附來源連結，避免長篇逐字引用。

## 輸出格式

```text
結論：...
依據：...
限制：...
來源：...
```

## 注意

- 高風險醫療、法律、財務、資安主題需提醒專業或官方確認。
- 來源衝突時列出衝突，不強行合併。
- 不能查證時明確說明限制。
